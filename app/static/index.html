How a result is built

  1. The list is split and matched to the library. Unmatched names stay unknown.
  2. Concerns are copied from retrieved notes. A model cannot add a source that was not retrieved.
  3. A name you asked to avoid is labeled as your preference, not as a new scientific fact.

Barcode scanning and photo OCR are not in this version. The same analysis accepts text from those later.

How a check is decided

  1. Your profile sets the rules: acne, eczema, pregnancy, a fragrance allergy, a steroid medicine.
  2. The ingredient names are matched to a fixed library. The same list always gives the same result.
  3. A chatbot does not invent the verdict. If a name is not in the library, COSMIX says it does not know.
