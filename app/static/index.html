How a check is decided

  1. Your profile sets the rules: acne, eczema, pregnancy, a fragrance allergy, a steroid medicine.
  2. The ingredient names are matched to a fixed library. The same list always gives the same result.
  3. A chatbot does not invent the verdict. If a name is not in the library, COSMIX says it does not know.
